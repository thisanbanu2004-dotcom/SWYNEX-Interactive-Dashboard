# SWYNEX Interactive Customer Sales Dashboard

## Project Overview
This project was developed as part of the SWYNEX Technologies Data Analyst Internship – Task 3.

The dashboard was created using **Microsoft Power BI** to analyze customer sales data and present important business insights through interactive visualizations.

## Tools Used
- Microsoft Power BI Desktop
- CSV Dataset
- DAX (Data Analysis Expressions)

## Dataset
The project uses the cleaned customer sales dataset containing customer details, purchase amounts, gender, age, country, and feedback scores.

## Key Performance Indicators (KPIs)
- Total Customers
- Total Sales
- Average Purchase
- Average Age

## Dashboard Visualizations
- Customers by Country
- Gender Distribution
- Age Distribution
- Feedback Score Distribution

## Interactive Filters
- Country
- Gender
- Age

## Key Features
- Interactive dashboard
- Customer sales analysis
- KPI cards
- Charts and visualizations
- Dynamic filters
